How to install

CutVid is not in the app stores yet, so the first install takes a few extra taps.

iPhone and iPad

  1. Install Sideloadly on a computer.
  2. Connect your iPhone with a cable and drag the IPA into Sideloadly.
  3. Enter your Apple ID and press Start.
  4. On the iPhone: Settings → General → VPN & Device Management → trust your Apple ID.

Android

  1. Open the downloaded APK.
  2. If asked, allow your browser to install apps.
  3. Tap Install.

Windows

  1. Run the installer.
  2. If SmartScreen appears, choose More info → Run anyway.

Mac

  1. Open the DMG and drag CutVid to Applications.
  2. The first time, right-click CutVid and choose Open.
